4. COMPONENT CONTRACT — every component must satisfy all of this
────────────────────────────────────────
API

Accessibility — WCAG 2.1 AA, verified with axe, zero serious or critical violations

Performance — this runs on 16GB RAM and a GTX 1650 while video is decoding
- 60fps interactions: animate only transform and opacity; will-change sparingly; memoize list rows; virtualize lists over 100 rows with @tanstack/react-virtual; no layout thrash in pointer handlers (batch reads and writes, use requestAnimationFrame).
- Pointer Events with setPointerCapture; touch and pen safe; no document-level listeners left behind (clean up in effects).
- No re-render storms: no new object or array literals passed to memoized children; stable callbacks.

Robustness
- Handles extremely long Persian and English strings (truncate with title), 0 items, 10,000 items, missing optional data, NaN or negative durations (clamp), window resize, high-DPI.
- Error-boundary friendly: never throw during render on bad data — render the error state.

Testing — Vitest + Testing Library + user-event + jest-axe; the reviewer will run these
- For each component: renders in fa/RTL and en/LTR; full keyboard path works end to end; every state renders; expect(await axe(container)).toHaveNoViolations(); callback contracts hold (onChange fires with the right value exactly once per interaction).

────────────────────────────────────────
